لعبة "على جنب يا اسطى": لينك تلعب منه على كروم + زرار "حمّل التطبيق (APK)"  — كله أوتوماتيك ومجاني

اللي هتاخده في الآخر: لينك زي  https://اسمك.github.io/اسم-الريبو/
- بتفتحه في كروم وتلعب مباشرة.
- بيظهر تحت زرار "يلا بينا" زرار "📥 حمّل التطبيق (APK)" على أندرويد، بينزّل ملف الـ APK، وبتركّبه.
- وكمان كروم بيعرض "تثبيت التطبيق" (PWA).

أنا ما أقدرش أرفع أو أبني على النت من عندي، فالمشروع ده بيعمل كل ده على GitHub لوحده (المرة الأولى حوالي ١٠ دقايق):

1) اعمل حساب مجاني على github.com ثم New repository (اسمه مثلًا ala-ganb، خليه Public).
2) ارفع محتوى المجلد ده كله (Add file > Upload files): مجلد www + package.json + capacitor.config.json + مجلد assets.
   لو مجلد .github (المخفي) ما اترفعش: Add file > Create new file، اكتب في الاسم:  .github/workflows/android.yml
   وانسخ جواه محتوى ANDROID-WORKFLOW.yml.txt ثم Commit.
3) فعّل الصفحات: Settings > Pages > Build and deployment > Source: اختار "GitHub Actions".
4) افتح تبويب Actions: هتلاقي "Build APK and publish site" شغّال (أو اضغط Run workflow). استنى للعلامة الخضراء.
5) في الـ run هتلاقي الخطوة deploy وفيها لينك الموقع. ده لينك اللعبة. ابعته لأي حد.
   (وكمان ملف APK متاح في Artifacts باسم ala-ganb-apk.)

ملاحظات:
- النسخة debug وتتركّب على أي موبايل أندرويد (اسمح بالتثبيت من مصدر غير معروف). لنسخة Google Play نعمل release موقّعة.
- الـ APK بيشتغل بدون إنترنت وبالعرض وملء الشاشة، وحساس الإمالة بيشتغل فيه.
- أي تحديث للعبة: ارفع الملفات المعدّلة في www وهيتبني ويتنشر تاني لوحده.
- لو الـ workflow فشل: افتح السجل وابعتلي لقطة الخطأ وأصلحه.
